# Prototype

打开 [`agent-hub-prototype-v2.html`](agent-hub-prototype-v2.html) 即可查看交互原型，无需安装依赖。

该原型用于验证：

- 可扩展的 Agent 列表
- Agent 选择上下文
- Agent 程序、配置目录与资源之间的关系
- 资源清单
- 发现依据
- 手动添加和扫描反馈

所有数据与系统操作均为浏览器内模拟，不会访问或修改本地 Agent 文件。

视觉和文案遵循 [`docs/design-system.md`](../docs/design-system.md)：Notion 风格、单一蓝色结构强调、统一无衬线字体和中文优先。
