# Agent Hub UI 设计规范

## 1. 规范地位

本文件是 Agent Hub 后续 UI 设计和实现的视觉基线，来源于项目提供的 `DESIGN-notion (1).md`。

适用范围：

- 产品原型
- React 页面
- Tauri 桌面窗口
- 空状态、错误状态和系统弹窗
- 项目截图与交互演示

新增页面或组件不得自行引入另一套字体、结构色、阴影语言或默认英文信息架构。需要偏离时，先记录设计原因并更新本文件。

## 2. 设计原则

Agent Hub 应当像一张整理良好的工作桌：

- 暖纸色背景降低工具界面的冷硬感。
- 白色内容表面依靠细边框和极轻阴影建立层级。
- 近黑文字承担主要信息，灰色文字承担说明。
- `#0075DE` 是唯一结构强调色，只用于主操作、链接、选择和焦点。
- 绿色、橙色、粉色、紫色等只用于小面积状态或装饰，不参与页面结构。
- 信息层级主要依靠字重、字号、间距和留白，不依靠大面积色块。

## 3. 颜色

```css
:root {
  --color-primary: #0075de;
  --color-primary-active: #005bab;
  --color-secondary: #213183;
  --color-canvas: #ffffff;
  --color-canvas-soft: #f6f5f4;
  --color-surface: #ffffff;
  --color-ink: rgba(0, 0, 0, 0.95);
  --color-ink-secondary: #31302e;
  --color-ink-muted: #615d59;
  --color-ink-faint: #a39e98;
  --color-hairline: #e6e6e6;
  --color-success: #1aae39;
  --color-warning: #dd5b00;
  --color-danger: #dc2626;
}
```

规则：

1. 同一页面只允许一个蓝色主操作。
2. 当前选择可以使用透明度较低的蓝色背景。
3. 状态色只出现在状态点、图标、短标签和提示文本中。
4. 不使用青绿色或紫色绘制页面主结构线。
5. 不使用纯白作为整个应用背景；大面积画布优先使用 `canvas-soft`。

## 4. 字体

```css
--font-ui:
  "NotionInter",
  "Inter",
  -apple-system,
  system-ui,
  "Segoe UI",
  Helvetica,
  Arial,
  sans-serif;

--font-mono:
  ui-monospace,
  "SF Mono",
  "JetBrains Mono",
  Menlo,
  Monaco,
  Consolas,
  monospace;
```

使用规则：

- 标题、正文、按钮、导航、状态和表格使用 `font-ui`。
- 只有文件路径、命令、版本原文、哈希和实例 ID 使用 `font-mono`。
- 不使用 Bahnschrift、窄体、像素字体或独立的技术面板字体。
- 正文默认 400，按钮和标题使用 500–700。

推荐桌面层级：

| 角色 | 字号 | 字重 | 行高 | 字距 |
|---|---:|---:|---:|---:|
| 页面标题 | 26px | 700 | 1.23 | -0.625px |
| 区域标题 | 20px | 600 | 1.4 | -0.125px |
| 卡片标题 | 16px | 600 | 1.4 | 0 |
| 正文 | 15px | 400 | 1.5 | 0 |
| 辅助正文 | 14px | 400 | 1.43 | 0 |
| 小标签 | 12px | 600 | 1.33 | 0.125px |

## 5. 间距与形状

基础单位为 4px，主要节奏为：

```text
4 / 8 / 12 / 16 / 24 / 28 / 32
```

圆角：

| 类型 | 圆角 |
|---|---:|
| 输入框、小标签 | 4px |
| 菜单项、状态标签 | 5px |
| 工具按钮、小卡片 | 8px |
| 内容卡片 | 12px |
| 大型容器、弹窗 | 16px |
| 主要营销按钮 | 全圆角 |

桌面工具中的“打开目录”“重新扫描”等工具按钮使用 8px 圆角，不使用营销式全圆角。

## 6. 层级与阴影

默认卡片使用 1px `hairline`，不加阴影。

需要抬升时使用：

```css
box-shadow:
  rgba(0, 0, 0, 0.04) 0 4px 18px,
  rgba(0, 0, 0, 0.027) 0 2px 7.85px,
  rgba(0, 0, 0, 0.02) 0 0.8px 2.93px,
  rgba(0, 0, 0, 0.01) 0 0.175px 1.04px;
```

禁止使用明显的黑色硬阴影。

## 7. 中文优先的文案体系

默认语言为简体中文。

### 7.1 可以保留的英文

- 产品或协议名称：Agent、Skill、MCP、SQLite
- 文件格式：JSON、JSONC、TOML、YAML、Markdown
- 操作系统术语：PATH、WSL
- 品牌名称：Claude Code、Codex、Hermes
- 文件名、路径、命令、版本号和代码标识

### 7.2 必须翻译的用户概念

| 不直接展示 | 默认中文 |
|---|---|
| Runtime | Agent 程序 |
| Config root | 配置目录 |
| Resources | 资源 |
| Resource map | 资源清单 |
| Discovery evidence | 发现依据 |
| Metadata | 基本信息 |
| Ready | 正常 |
| Changed | 有变化 |
| Config only | 仅发现配置 |
| Missing | 路径失效 |
| Invalid | 无法识别 |
| Disabled | 已停用 |

### 7.3 工程实现

- UI 文案必须通过 i18n key 获取。
- 领域状态码保持稳定英文，例如 `config_only`。
- DTO 不返回最终展示文案；前端通过状态码映射当前语言。
- 错误信息包含稳定错误码和本地化展示文案。
- 禁止在组件 JSX 中散落硬编码英文。

## 8. Agent Hub 特有组件

### 8.1 资源关系

```text
Agent 程序 ───── 配置目录 ───── 已发现资源
```

这条关系线用于解释 Agent Hub 的核心数据模型：

- 第一个节点说明程序是否存在和版本是否可验证。
- 第二个节点说明配置目录是否存在且可访问。
- 第三个节点说明已识别资源数量及变化。

正常连接线使用主蓝色；异常只改变对应节点的小面积状态，不改变整个组件背景。

### 8.2 Agent 清单

- 使用纵向紧凑列表，支持 20–50 个 Agent。
- 每行只展示名称、路径摘要、最后扫描时间和状态。
- 当前行使用浅蓝背景和蓝色左侧指示。
- 不使用大面积品牌色卡片。

### 8.3 资源清单

- 表头使用同一 UI 字体，不使用全大写英文。
- 文件名或路径可以使用等宽字体。
- 敏感资源显示“含敏感信息”，不显示正文预览。

## 9. 可访问性

- 键盘焦点使用半透明主蓝色焦点环。
- 正文与背景保持可读对比度。
- 状态不能只依赖颜色，必须同时提供中文标签。
- 移动端交互目标不小于 44×44px。
- 尊重 `prefers-reduced-motion`。

## 10. UI 评审检查表

每次合并 UI 变更前检查：

- [ ] 是否使用 Notion 风格 Token？
- [ ] 是否仍然只有一个结构强调色？
- [ ] 是否使用统一 UI 字体？
- [ ] 等宽字体是否只用于真实技术内容？
- [ ] 默认可见文案是否为中文？
- [ ] 英文是否属于必要技术名词？
- [ ] 状态是否同时包含文字说明？
- [ ] 是否存在过重阴影或大面积状态色？
- [ ] 是否验证 1440px、1080px 和窄窗口布局？
- [ ] 是否验证键盘焦点和 reduced motion？
